Kebijakan Privasi

Terakhir diperbarui: Januari 2026

1. Informasi yang Kami Kumpulkan

Kami mengumpulkan informasi yang Anda berikan langsung kepada kami saat:

  • • Membuat akun (username, email, password)
  • • Membuat API key
  • • Menghubungi kami untuk dukungan

2. Data Penggunaan API

Kami secara otomatis mengumpulkan informasi tertentu saat Anda menggunakan API kami:

  • • Endpoint API yang diakses
  • • Waktu request
  • • Waktu respons
  • • Alamat IP

3. Bagaimana Kami Menggunakan Informasi Anda

Kami menggunakan informasi yang kami kumpulkan untuk:

  • • Menyediakan dan memelihara Layanan kami
  • • Memantau penggunaan API dan menerapkan batas rate
  • • Mendeteksi dan mencegah penyalahgunaan
  • • Meningkatkan Layanan kami
  • • Berkomunikasi dengan Anda tentang pembaruan

4. Keamanan Data

Kami menerapkan langkah-langkah keamanan yang sesuai untuk melindungi informasi pribadi Anda. Password di-hash dan API key dibuat dengan aman. Namun, tidak ada metode transmisi melalui Internet yang 100% aman.

5. Penyimpanan Data

Kami menyimpan informasi akun Anda selama akun Anda aktif. Log API disimpan selama 90 hari untuk keperluan analitik dan debugging.

6. Layanan Pihak Ketiga

Kami tidak menjual, memperdagangkan, atau membagikan informasi pribadi Anda kepada pihak ketiga untuk tujuan pemasaran. Kami mungkin membagikan data anonim dan agregat untuk analitik.

7. Hak Anda

Anda memiliki hak untuk:

  • • Mengakses data pribadi Anda
  • • Meminta koreksi data yang tidak akurat
  • • Meminta penghapusan akun Anda
  • • Mengekspor data Anda

8. Hubungi Kami

Jika Anda memiliki pertanyaan tentang Kebijakan Privasi ini, silakan hubungi kami di privacy@coffeespot.id
