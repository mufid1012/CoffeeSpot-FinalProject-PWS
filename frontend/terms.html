1. Penerimaan Persyaratan

Dengan mengakses dan menggunakan CoffeeSpot API ("Layanan"), Anda menyetujui untuk terikat dengan Syarat dan Ketentuan ini. Jika Anda tidak menyetujui persyaratan ini, harap jangan gunakan Layanan.

2. Deskripsi Layanan

CoffeeSpot API menyediakan layanan API RESTful yang memungkinkan developer mengakses data coffee shop termasuk lokasi, rating, fasilitas, dan informasi terkait lainnya.

3. Penggunaan API

  • • Anda harus mendaftar akun untuk mendapatkan API key
  • • API key hanya untuk penggunaan Anda dan tidak boleh dibagikan
  • • Paket gratis dibatasi 100 request per hari
  • • Anda tidak boleh menggunakan API untuk tujuan ilegal
  • • Anda tidak boleh mencoba melewati batas rate limit

4. Hak Kekayaan Intelektual

Layanan beserta konten asli, fitur, dan fungsionalitasnya dimiliki oleh CoffeeSpot dan dilindungi oleh hak cipta internasional, merek dagang, dan hukum kekayaan intelektual lainnya.

5. Batasan Tanggung Jawab

CoffeeSpot tidak bertanggung jawab atas kerusakan tidak langsung, insidental, khusus, konsekuensial, atau hukuman yang diakibatkan oleh penggunaan Layanan oleh Anda.

6. Penghentian

Kami berhak menghentikan atau menangguhkan akses Anda ke Layanan segera, tanpa pemberitahuan sebelumnya, untuk perilaku yang kami yakini melanggar Ketentuan ini atau berbahaya bagi pengguna lain.

7. Perubahan Ketentuan

Kami berhak mengubah ketentuan ini kapan saja. Kami akan memberitahu pengguna tentang perubahan apa pun dengan memperbarui tanggal "Terakhir diperbarui".
