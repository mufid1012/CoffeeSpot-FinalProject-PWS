Quick Start

Mulai gunakan CoffeeSpot API hanya dalam 3 langkah sederhana

1️⃣

Register

Buat akun gratis untuk mendapatkan akses ke developer dashboard.

2️⃣

Get API Key

Generate API Key dari dashboard untuk mengakses endpoint.

3️⃣

Start Coding

Gunakan API Key untuk mulai mengakses data coffee shop.

cURL 
# Get list of coffee shops
curl -X GET "https://api.coffeespot.id/api/coffeeshops" \
  -H "x-api-key: YOUR_API_KEY"

# Response
{
  "success": true,
  "data": [
    {
      "id": 1,
      "name": "Kopi Kenangan",
      "address": "Jl. Sudirman No. 123",
      "city": "Jakarta",
      "rating": 4.5,
      "facilities": ["WiFi", "AC", "Parking"]
    }
  ]
}
